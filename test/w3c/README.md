# W3C SPARQL test queries

The queries in this directory are copied from the SPARQL 1.0, 1.1 and 1.2 test suites in
[w3c/rdf-tests](https://github.com/w3c/rdf-tests) (commit `369a90d`) by
`scripts/import-w3c-tests.mjs`. `index.json` lists every query with its test type and whether it is valid
SPARQL (`positive`).

They are distributed under the [W3C test suite licenses](https://www.w3.org/Consortium/Legal/2008/04-testsuite-copyright.html),
see [LICENSE.md](LICENSE.md).
